# 엔지니어링 영업추진현황 · 주간 제출본 만들기

엑셀에서 **복사 → 붙여넣기**만으로 이번 주 제출본(xlsx)을 원본 서식 그대로 만드는 단일 페이지 도구입니다.
붙여넣은 내용은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다. 이 저장소에는 업체 데이터가 없습니다.

## 매주 사용 순서
1. **지난주 제출본 붙여넣기**: 지난주 제출본의 세 시트를 시트마다 전체 선택(Ctrl+A)한 뒤 복사(Ctrl+C)해서 해당 칸에 붙여넣습니다.
   - `영남영업본부`
   - `영남대상업체(수주풀)`
   - 3번째 시트(재영업 등, 선택)
   - 필터가 걸려 있으면 먼저 해제합니다.
   - 수주풀의 솔루션 사업구분(G~P)이 그룹으로 접혀 있으면 복사되지 않아 O 표시가 빠집니다. 열 위쪽 [+]로 펼친 뒤 복사합니다. 빠진 채로 붙이면 화면에 경고가 뜨고, 권역 자료에 있는 O 표시로 채웁니다.
2. **이번 주 권역 자료 붙여넣기**: 권역 담당 파일의 수주풀 시트 전체를 해당 권역 칸에 붙여넣습니다. 그 권역의 업체 행만 반영됩니다.
   - 아래 **권역 재영업·창고이슈업체** 칸(선택)에는 권역 파일의 `재영업 및 창고이슈업체` 시트 전체를 붙여넣습니다. 그 권역 행 중 주차 또는 방문실적이 보고 주차인 행만 반영하고, 새 업체는 표 끝에 추가합니다.
3. **보고 주차 확인 → 자료생성**: 이번 주 방문 업체마다 배치를 고릅니다.
   - 배치: `▶ 금주 주요 업체` / `▶ 전주 재방문 업체` / 선택 안 함
   - 본부 체크: `▶본부 주요업체` 바로 아래 `◎ 금주 주요 업체`에 들어갑니다(주차·추가 진행 현황 포함). `◎ 본부 니즈/견적 리스트`에도 반영해, 리스트에 있으면 추가진행 주차·현황을 갱신하고 없으면 맨 아래에 추가합니다.
   - 기본 배치: 금주 신규방문 → `▶ 금주 주요 업체`, 재방문 → `▶ 전주 재방문 업체`, LE 동행방문 → `▶ 전주 LE 동행방문 업체`. 바꿀 수 있습니다.
   - 본부 체크박스는 기본 해제입니다. 본부 주요업체에 넣을 업체만 체크합니다.
   - 고른 뒤 표 아래 **배치·본부 확정**을 누릅니다. 엑셀은 확정한 선택으로 만들어집니다. 확정 후 선택을 바꾸면 다시 확정해야 합니다.
   - 점검 열: 사업구분 O 표시와 추진과제가 맞는지 표시합니다(예: 추진과제는 자동화창고인데 기타설비에만 O).
   - 수정이력 열: 오탈자·띄어쓰기 자동 수정 내역을 보여줍니다.
   - 붙여넣기 칸마다 **초기화** 버튼이 있습니다.
4. **② 업체 수정 탭**
   - 표를 고른 뒤 업체를 선택하고 내용을 고쳐 **본문 변경 저장**을 누릅니다. 수주풀과 앞시트(금주 주요 업체·본부 리스트 등)에 함께 반영됩니다.
   - 표 종류
     - 수주풀: 금주 업데이트 / 금주 신규방문 / 재방문 / LE 동행 / 직접 추가한 업체 / 전체 업체
     - 보고: 금주 주요 업체 / 본부 주요업체 / 앞시트 별도 목록(LE 동행방문 대상, LE 차주 방문요청, 계약성사 가능성)
   - 입력 방식: 진행단계는 선택형, 솔루션 사업구분(O 표시)은 추진과제 옆 드롭다운(복수 선택)입니다. Needs 칸은 크게 열리고 크기를 조절할 수 있습니다.
   - **업체 추가**: 신규 업체는 오른쪽 폼을 채워 저장합니다. 앞시트 별도 목록에서는 행이 추가됩니다.
   - **선택 업체 삭제**: 수주풀과 앞시트에서 함께 빠집니다.
5. **엑셀 제출본 만들기**를 누르면 확인 창이 뜹니다.
   - 확정한 배치·본부(금주 주요·재방문·본부 금주 주요 업체 목록)와 업체 수정 내역을 보여 주고 진행합니다.
   - 확정하지 않았거나 확정 후 선택이 바뀌었으면 알려 주고, "확정하고 생성"으로 지금 선택을 확정해 진행할 수 있습니다.

## 서식을 유지하는 방법
- 붙여넣기에는 서식이 없습니다. 그래서 실제 제출본에서 데이터를 모두 지우고 **서식·수식·라벨만 남긴 빈 틀(`kit.js`)**에 값을 채웁니다.
- 채우는 대상은 색, 글자 크기, 테두리, 병합, 열 너비, 행 높이, 수식입니다.
- 과거분 업체(월구분이 `25 3Q`, `2510` 같은 행)는 원본처럼 회색 행으로 넣습니다.

## 처리 규칙
- **수주풀**
  - 권역 자료에서는 **보고 주차에 방문한 행**(방문실적 신규·재방문·LE동행 중 하나가 보고 주차)만 원문 그대로 반영합니다. 그 외 행은 권역 자료가 달라도 지난주 제출본(붙여넣은 시트) 그대로 둡니다.
  - 서식은 붙여넣은 지난주 시트의 행 서식을 따릅니다. 과거분 회색 행은 월구분이 `25 3Q`·`2510`처럼 과거분일 때만이고, 월구분이 비어 있는 행과 새 업체는 흰 행입니다.
  - 코드와 업체명으로 매칭하고, 새 업체는 해당 권역 블록 끝에 넣습니다.
  - 계산 열(재방문여부, 동행방문여부, 단계(보고용), 금주방문, 당월방문)은 수식으로 다시 채웁니다.
- **영남영업본부**
  - X1 보고주차와 X3 당월을 갱신합니다.
  - 방문실적 표는 보고주차 열에 수식을 추가하고, 합계·누계·당월 범위와 라벨을 옮깁니다.
  - 상단 집계표는 제출본 수식 그대로 두고, 파일을 열면 재계산됩니다.
- **하단 목록**
  - `▶ 금주 주요 업체`: 선택한 업체의 Needs를 옮깁니다. 1. / 2. / 3. 항목 사이는 한 줄씩 띄우고, 글자가 모두 보이게 행 높이를 맞춥니다.
  - `▶ 전주 LE 동행방문 업체`: LE동행방문실적이 보고주차인 업체를 자동으로 넣습니다.
  - `▶ 계약성사 가능성 업체`: 원본처럼 접힌 그룹(숨김)을 유지합니다.
  - `▶ 금주 주요 업체` 위 목록(LE 동행방문 대상·LE 차주 방문요청·계약성사 가능성)은 맑은 고딕 10, 줄바꿈으로 맞추고 행 높이를 글자에 맞춥니다(최소 26.25).
  - `▶본부 주요업체` 바로 아래(빈 행 없이) `◎ 금주 주요 업체`: 화면에서 본부 체크한 업체를 권역 순, 매출 상위 순으로 넣습니다. 지난주 행은 지웁니다.
  - `◎ 본부 니즈/견적 주요 업체 리스트`: 3번째 시트의 두 표로 만듭니다. 제목 아래 `재영업 대상` 표(추가진행 주차·추가 진행현황), 한 줄 띄고 `창고이슈업체` 표(신축/이전시기·주차·추가 진행현황) 순서입니다. 붙여넣기로는 숨김(그룹) 정보가 넘어오지 않아, 숨겨 둔 행은 펼쳐진 상태로 나옵니다.
  - 새로 니즈확인·견적·계약이 된 업체와 본부 체크 업체는 재영업 대상 맨 아래에 권역 순, 매출 상위 순으로 추가합니다(3번째 시트에도 같이 추가).
- **오탈자·띄어쓰기 자동 수정** (수주풀과 앞시트 서술에 똑같이 적용)
  - 확실한 오탈자만 사전으로 고칩니다. 예: 현항→현황, 셔틀렉→셔틀랙, 없슴→없음, 효률→효율, 무인지게차 오기.
  - 띄어쓰기는 중복 공백, 쉼표·괄호 주변, "28년4Q"→"28년 4Q"를 정리합니다.
- **수주풀**
  - 숨긴 행·열을 모두 펼칩니다. 필터는 걸지 않고, 화면 배율은 85%입니다.
  - 솔루션 사업구분(G~P)은 열 그룹으로 묶습니다(펼친 상태, 위쪽 −/+ 버튼으로 접기).
  - 주요 이슈(Needs) 오른쪽의 머리글 없는 빈 열(예전 AB~AE)은 지웁니다. 비고·월구분은 AB·AC로 당겨지고, 앞시트 집계 수식의 참조(단계(보고용)·금주방문·당월방문)도 함께 옮깁니다. 예전 양식 권역 자료를 붙여도 머리글 기준으로 맞춰 들어갑니다.
  - 비고·월구분이 비어 있으면 채웁니다. 비고는 그룹/일반 값(없으면 '신규'), 월구분은 첫 방문월입니다.
- **월 전환**: 새 달이 되면 방문실적 표의 9월 4주 옆 열에 새 달 주차 열을 추가합니다. 합계·누계·당월과 숨김 보조 열은 오른쪽으로 옮기고 참조 수식도 함께 고칩니다.
- **3번째 시트(재영업 및 창고이슈업체)**: 붙여넣은 지난주 내용에 권역 재영업·창고이슈 붙여넣기(보고 주차 행만)와 본부 추가를 반영합니다. 3번째 시트를 붙여넣지 않으면 앞시트 리스트는 지난주 리스트를 기준으로 만듭니다.

## 알려진 제한
- **붙여넣기로 사라지는 것**
  - 셀별로 손으로 칠한 강조색(일부 행의 파란 강조, 노란 표시 등)은 복원되지 않습니다.
  - 금액은 화면에 보이는 자리수로 복사됩니다. 예를 들어 11.87은 11.9로 들어옵니다.

## 파일
- `index.html`: 화면
- `engine.js`: 붙여넣기 복원·병합·갱신 로직. 브라우저와 Node에서 공용으로 씁니다.
- `kit.js`: 서식 틀(데이터 없는 xlsx, base64)
- `tools/make-kit.js`: 제출본 양식이 바뀌었을 때 틀을 다시 만듭니다.
  - 사용법: `node tools/make-kit.js 제출본.xlsx`
  - 업체명·담당자·서술이 남아 있으면 중단합니다.
- `vendor/`: [ExcelJS](https://github.com/exceljs/exceljs) 4.4.0 (MIT), [JSZip](https://github.com/Stuk/jszip) 3.10 (MIT)
