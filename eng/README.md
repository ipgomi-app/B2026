# 엔지니어링 영업추진현황 · 주간 제출본 만들기

지난주 제출본(xlsx)과 경북/부산/경남 권역 자료를 넣으면, 원본 서식 그대로 이번 주 제출본(xlsx)을 만들어 주는 단일 페이지 도구입니다.
파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다. 이 저장소에는 업체 데이터가 들어 있지 않습니다.

## 사용 순서
1. **지난주 제출본**을 올립니다. 이 파일이 템플릿이 되어 서식·수식·3번째 시트(재영업 등)를 그대로 따릅니다.
2. **권역 자료**를 올립니다.
   - 권역 담당이 보낸 엑셀(수주풀 시트 포함) 3개를 한 번에 끌어다 놓으면 권역을 자동으로 판별합니다.
   - 엑셀 대신 시트 내용을 헤더 행까지 복사해서 붙여넣어도 됩니다.
3. **보고 주차**를 확인하고 병합 미리보기를 누릅니다. 이번 주 방문 업체 중에서 `▶ 금주 주요 업체`에 넣을 업체를 고릅니다.
4. (선택) LE 동행방문 대상 / LE 차주 방문요청 / 계약성사 가능성 목록을 바꿀 때만 붙여넣습니다.
5. **엑셀 제출본 만들기**를 누르면 파일이 내려받아집니다. 만든 제출본은 브라우저에 저장되어 다음 주 템플릿으로 바로 쓸 수 있습니다.

## 처리 규칙
- **대상업체(수주풀)**
  - 권역 파일의 해당 권역 행으로 교체합니다. 값과 셀 서식을 원문 그대로 가져오며, 요약하거나 고치지 않습니다.
  - 코드와 업체명으로 매칭합니다.
  - 새 업체는 해당 권역 블록 끝에 추가합니다.
  - 권역 파일에서 빠진 업체는 삭제하고, 미리보기에 표시합니다.
  - 계산 열(재방문여부, 동행방문여부, 단계(보고용), 금주방문, 당월방문)은 템플릿 수식으로 다시 채웁니다.
- **영남영업본부(요약)**
  - X1 보고주차와 X3 당월을 갱신합니다.
  - 방문실적 표는 보고주차 열에 수식을 추가하고, 합계·누계·당월 범위와 라벨을 옮깁니다.
  - 상단 집계표는 템플릿 수식 그대로 두고, 파일을 열면 재계산됩니다.
- **하단 목록**
  - `▶ 금주 주요 업체`: 선택한 업체의 `주요 이슈 및 고객사 Needs`를 원문 그대로 옮깁니다.
  - `▶ 전주 LE 동행방문 업체`: LE동행방문실적이 보고주차인 업체를 넣습니다.
  - `◎ 금주 주요 업체` / `◎ 본부 니즈·견적 리스트`: 리스트 업체가 이번 주에 방문하면 추가진행 주차와 현황을 반영합니다.
- 템플릿에 있던 숨김 "정의된 이름" 잔재(수천 개, `#REF!` 등)는 제거합니다. 파일을 여는 속도 때문이며, 시트 내용에는 영향이 없습니다.

## 알려진 제한
- 월이 바뀌어 템플릿 방문실적 표에 새 달의 주차 열이 없으면, 주차 열 갱신은 건너뛰고 경고를 띄웁니다.

## 파일
- `index.html`: 화면
- `engine.js`: 병합·갱신 로직. 브라우저와 Node에서 공용으로 씁니다.
- `vendor/`: [ExcelJS](https://github.com/exceljs/exceljs) 4.4.0 (MIT), [JSZip](https://github.com/Stuk/jszip) 3.10 (MIT)
