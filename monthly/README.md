# 영남영업본부 · 월간 영업회의자료 만들기

엑셀에서 **복사 → 붙여넣기**만으로 월간 영업회의자료(xlsx, 3시트)를 완성본 서식 그대로 만드는 단일 페이지 도구입니다.
붙여넣은 내용은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다. 이 저장소에는 업체 데이터가 없습니다.

출력 시트: `영남영업본부`, `(영남)하반기 신규추진계획`, `(영남)하반기 신규추진(세부)`
(신규추진 2시트는 지금은 틀 그대로 들어가며 별도로 작업할 예정입니다.)

## 매월 사용 순서
1. **① 붙여넣기 · 배치**
   1. **영남영업본부 양식**: 이번 달 받은 양식의 영남영업본부 시트를 B1부터 끝까지 복사해 붙여넣습니다.
      - 기준월(T1)을 읽어 전월 실적(기준월)과 당월 계획(기준월+1)을 정합니다.
   2. **사업별 계약·견적 데이터**: PPS·SCM·산업자재유통·글로벌비즈·지게차의 계약·견적 목록을 머리글 포함해 붙여넣습니다.
      - 전월·당월을 한꺼번에 붙여도 `월`로 나눕니다.
      - 손익개선(진행중·완료) 표도 붙여넣습니다.
   3. **타겟업체·농산업종**: 요약표와 목록을 각각 붙여넣습니다.
   4. **출력 건수·최소 금액**: 사업·단계마다 최대 건수와 최소 금액(천원)을 조정합니다. 최대 건수 0은 전 건입니다.
   5. **점검 요약·중복 업체 배치**: 점검 결과를 확인하고, PPS 사업·타겟·농산에 겹친 업체(전월·당월끼리도 비교)는 넣을 목록만 체크합니다(기본: 타겟·농산만). 결재완료가 아닌 행(반려·미결재)은 따로 표로 보여주고 체크한 행만 넣습니다. 체크를 풀어도 업체 행만 빠지고 머리글 건수·금액은 그대로입니다.
2. **② 목록 수정**: 엑셀에 들어갈 행을 확인합니다. `넣기` 체크를 풀면 빠지고, 구분·세부내용을 고칠 수 있습니다.
3. **③ 서술 · 계획 문장**
   - 본부 중점 추진사항, 권역별 영업추진 계획, PPS 아래 손익개선 한 줄(상위 업체)을 입력합니다.
   - 타겟업체·농산업체 당월 계획은 비슷한 업체를 묶은 초안이 들어가 있으니 고쳐 씁니다.
4. **엑셀 만들기**를 누르면 파일을 받습니다. 입력은 브라우저에 저장되어 다시 열어도 남아 있습니다.
   - 붙여넣기 칸마다 **초기화** 버튼이 있습니다.

## 처리 규칙
- **전월 실적 현황 / 당월 계획 합계표**: 양식 데이터 구역의 기준월 열과 1월~기준월 누계(당월은 기준월+1)로 자동 작성합니다.
  - 사업 칸은 양식에 보이는 숫자 그대로(누계는 양식 누계 열), 합계 칸(당월·누계)은 맨 위 권역 합계표 값입니다.
- **영남 필터**: 부서가 12개 지점(부산·양산·울산·포항 / 김해·창원·진주·제주 / 구미·대구·영천·안동)이나 3개 권역이거나, 본부가 영남영업본부인 행만 넣습니다.
  - 부서가 없으면 같은 코드의 다른 행에서 가져옵니다(예: RRPP 계약).
- **사업 분류**: `계약형태`(01-PALLET, 03-SCM, 04-산업자재유통, 06-RRPP, 09-글로벌비즈)로 정합니다. 다른 사업 칸에 들어와도 옮깁니다.
- **열 찾기**: 머리글 이름으로 찾되, 머리글이 밀리거나 없을 때는 값 모양으로 찾습니다.
  - 금액: 계약은 계약구분 다음 숫자, 견적은 `01-연간` 다음 숫자
  - 세부내용: "지역, … 예상매출 …" 모양의 칸을 점수로 고름(보증금·미수금 같은 채권 문구 제외)
- **금액**: PPS 계약만 효과금액, 나머지는 예상매출액입니다(원 → 천원).
  - 지게차는 월 금액 × 12, 백 단위 반올림(7,777 → 7,800). 세부내용 예상매출도 같은 값
  - 타겟업체는 효과금액(年), 농산은 예상매출, 손익개선은 년예상효과(천원)
- **구분**
  - PPS: 재전환 / 점유율확대 / 신규
  - SCM: 중분류(운송 등), 산업자재: 소분류(`/` 앞), 글로벌비즈: RRPP·포워딩, 지게차: `지게차`
  - 타겟업체 SCM·산업자재는 세부내용의 품목(필름·골판지·파렛트·EPS·용기·비닐포장재 등)
  - 농산은 데이터의 구분 그대로
- **목록**: 사업 순서 PPS → SCM → 산업자재유통 → 글로벌비즈 → 지게차, 블록은 계약 → 견적(당월은 계약확정 → 협의중), 금액 큰 순입니다.
  - 기본 최소 금액: PPS·글로벌비즈·지게차 0.02억, SCM·산업자재 0.1억
- **머리글 "(N업체 X억)"**
  - 전월: 양식 값(PPS·글로벌비즈 견적&계약 본부계, SCM 전체+풀필먼트, 산업자재). 지게차는 데이터 합계(업체수·대수·금액)
  - 당월·손익개선·타겟·농산: 붙여넣은 데이터 기준
  - 억 표기: 1억 이상 소수 1자리, 미만 2자리, 끝 0 제거(3.0 → 3)
  - 0건이면 `(실적 없음)`
- **세부내용 다듬기**: 쉼표·띄어쓰기·확실한 오탈자를 고치고, 금액은 1,000천원(100만원) 이하 `N,NNN천원/년`, 초과 `X억/년`(1억 이상 소수 1자리, 1천만원 이상 2자리, 그 아래 3자리, 끝 0 없음)으로 씁니다. 손익개선은 예전대로 5,000천원 기준입니다.
- **결재상태**: 사업 데이터는 결재완료만 넣습니다. 반려·결재중 등은 `결재완료 아님` 표에서 골라 넣을 수 있습니다.
  - 지게차는 `지역, 장비 N대, 비고, 예상매출`로 만듭니다.
- **점검 요약**: 영남 외 제외, 기준월 아닌 행, 서술 속 예상매출 자동수정(금액 열 값으로), 담당자·코드 표시, 서술을 다른 열에서 찾음, 사업 옮김, 양식 머리글과 데이터 건수 차이를 보여줍니다.
- **손익개선 블록(당월)**: 완료 → 계약확정(적용월이 당월인 행), 진행중 → 협의중(전부).
- **양식 데이터 구역**: `※`·`▶` 제목 기준으로 행을 맞춰 값을 넣고, 합계·차이·달성율 수식은 틀 그대로 둡니다.
  - 전년동기누계(U열)는 양식에 없어 비워 두고, 증가율은 빈칸으로 둡니다.

## 알려진 제한
- 붙여넣기 숫자는 화면에 보이는 정수로 들어오므로, 완성본과 합계가 몇 천원 다를 수 있습니다.
- 경쟁사(BIGS)와 신규추진 2시트는 아직 자동화하지 않았습니다.

## 파일
- `index.html`: 화면 (`../eng/vendor`의 ExcelJS 4.4.0 · JSZip 3.10 사용)
- `engine.js`: 붙여넣기 해석·분류·엑셀 쓰기. 브라우저와 Node에서 공용으로 씁니다.
- `kit.js`: 서식 틀(데이터 없는 xlsx, base64)
- `tools/make-kit.js`: 완성본으로 틀을 다시 만듭니다. 업체명·서술이 남으면 중단합니다.
  - 사용법: `node tools/make-kit.js 완성본.xlsx`
- `tools/build-single.js`: 스크립트를 넣은 단일 HTML 파일을 만듭니다.
  - 사용법: `node tools/build-single.js 출력.html`
- `SPEC.md`: 확정된 규칙 정리
