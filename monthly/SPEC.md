# 월간 영업회의자료 · 확정 규칙 (1단계 정리)

업무 데이터(업체명·금액·서술)는 적지 않는다. 규칙만 적는다.

## 입력과 출력
- 입력: 매달 받는 `영남영업본부` 양식(B~T열, 보고 부분이 빈 상태)을 붙여넣는다.
  - 보고 부분 자리: 구역 라벨 3개(8월 영업실적현황 및 9월 영업추진계획 / 본부 영업타겟업체 / 농산 및 국고보조업체)와 빈 행.
  - 그 아래 데이터 구역(※ PPS 및 물류기기 사업부분 ~ ※ 로지스올 렌탈 사업부분)은 값으로 채운다. 행은 라벨 기준으로 맞춘다.
- 서식: 완성본에서 데이터를 지운 틀(kit). 시트 안 수식(합계·차이·달성율·1~24행 요약)은 유지한다.
- 출력: 3시트 — `영남영업본부`, `(영남)하반기 신규추진계획`, `(영남)하반기 신규추진(세부)`.
  - 신규추진 2시트는 이번엔 틀 그대로 넣고 별도 작업한다.

## ◎ 전월 실적 현황 / ◎ 당월 영업추진 계획 합계표
- 양식 데이터 구역의 기준월 열(당월)과 1월~기준월 누계(당월 계획은 기준월+1)로 자동 작성.
- 사업: PPS, 물류기기, SCM, 산업자재, RRPP&ULS. 권역: 경북, 부산, 경남, 영남.

## ◎ 전월 영업실적 주요 현황 (목록)
- 순서: PPS → SCM → 산업자재유통 → 글로벌비즈 → 지게차(MHE). 사업마다 계약 → 견적.
- 블록 안 정렬: 금액(효과금액) 큰 순.
- 기본 최소 금액: PPS·글로벌비즈·지게차 0.02억(2,000천원) 이상, SCM·산업자재 0.1억(10,000천원) 이상.
- 화면에서 사업별 계약·견적 출력 건수(와 최소 금액)를 조정한다.
- 행 원천: 붙여넣은 사업별 계약·견적 데이터(시스템 추출). 영남 12개 지점만 남긴다.
  - 부산권역: 부산·양산·울산·포항 / 경남권역: 김해·창원·진주·제주 / 경북권역: 구미·대구·영천·안동
- 열 대응(PPS)
  | 출력 | 계약 데이터 | 견적 데이터 |
  |---|---|---|
  | 부서명 | 부서 | 팀/권역 |
  | 구분 | 경쟁사구분이 재전환→재전환, 점유율확대→점유율확대, 그 외 계약구분에서 번호 뗀 값 | 점유율확대 열 동일 규칙, 그 외 영업구분 |
  | 업체명 | 계약처명 | 업체명 |
  | 예상매출(천원) | 효과금액(년) ÷ 1,000 | 효과금액 |
  | 세부내용 | 재고차이사유 및 계약내용 | 계약 특이사항 자리 서술 |
  - 머리글 이름으로 열을 찾는다(빈 머리글 포함).
  - SCM·산업자재·글로벌비즈·지게차 열 대응은 데이터를 받으며 추가.
- 세부내용 다듬기: 쉼표·띄어쓰기·오탈자 자동 수정. 예상매출 표기는 5,000천원 이하 `N,NNN천원/년`, 초과 `0.NN억/년`.

## 머리글 "(N업체 X억)"
- 전월: 양식 데이터 구역의 기준월 열에서.
  - PPS: 견적&계약 본부계(견적 건수·금액, 계약 건수·금액)
  - SCM: SCM 전체 + 풀필먼트 합산
  - 산업자재유통: 견적·계약 건수·금액
  - 글로벌비즈: 견적&계약 본부계
  - 지게차: 업체수·대수는 양식(견적실적·업체수·계약·계약업체수), 금액은 붙여넣은 지게차 데이터 합계
- 당월(계약확정/협의중): 붙여넣은 당월 데이터(영남 12개 지점 필터 후)로 건수·금액 계산.
  - 계약확정 = 당월 계약 데이터, 협의중 = 당월 견적 데이터.
  - 손익개선: 완료 = 계약확정, 진행중 = 협의중. 데이터는 따로 받는다.
- 억 표기: 1억 이상 소수 1자리, 1억 미만 소수 2자리(반올림). 끝이 0이면 뗀다(3.0 → 3, 0.30 → 0.3).
- 0건 블록: 머리글만 남기고 `실적 없음`으로 표기.

## PPS 아래 손익개선 한 줄
- 앞부분 `N업체 X억 : `은 양식 손익개선(단가인상) 표의 당월 실적 영남영업본부 행에서 자동.
- 뒤쪽 상위 업체 外 문구는 직접 입력.

## 사업 데이터 붙여넣기 공통
- 전월·당월 데이터를 한꺼번에 붙인다. `월`(없으면 `월별` YYMM, 기안일) 기준으로 기준월=전월 목록, 기준월+1=당월 목록으로 나눈다.
- 영남 필터: 부서가 12개 지점 또는 3개 권역이거나, 본부가 영남영업본부인 행만. 부서명 출력은 지점→권역으로 바꾼다.
- 사업 분류는 `계약형태` 열로 한다(01-PALLET→PPS, 03-SCM→SCM, 04-산업자재유통→산업자재, 09-글로벌비즈→글로벌비즈). 다른 사업 칸에 섞여 들어와도 옮긴다.
- 머리글이 빈 열이 많다. 이름 있는 머리글로 기준을 잡고, 빈 머리글 열은 내용으로 판별한다.
- 세부내용 찾기: 계약 데이터는 서술이 다른 열(예: 계약특이사항)에 있을 수 있다. 행의 글자 칸 중
  "지역(소재지), … 예상매출 …" 모양(첫 토막이 지역, `예상매출`·`물동량` 포함)을 점수로 골라 쓴다. 보증금·미수금 같은 채권 문구는 제외.

## 사업별 열 대응
| 사업 | 구분 | 금액 | 비고 |
|---|---|---|---|
| PPS | 경쟁사구분/점유율확대 → 재전환·점유율확대, 그 외 신규 | **계약만 효과금액**, 견적은 예상매출액 | 계약 데이터는 부서가 권역, `월별` YYMM |
| SCM | 중분류(번호 뗌: 운송 등) | 예상매출액 | 부서=지점 |
| 산업자재유통 | 소분류(`/` 앞: 필름, 식품용기 등) | 예상매출액 | 계약 데이터에 `년` 없음 |
| 글로벌비즈 | 계약형태 06-RRPP → RRPP, 09-글로벌비즈 → 중분류(포워딩) | 예상매출액 | RRPP 데이터는 머리글·년월·부서 열 없이 올 수 있음 |
| 지게차 | `지게차` | 확정 금액(계약)·견적 금액(견적) × 12 ÷ 1,000 (월→년, 천원) | 본부=영남영업본부 |

- 금액 단위: 원 → 천원(÷1,000).
- 지게차 세부내용: `지역(부서에서 '지점' 뗌), 장비2 N대, 비고, 예상매출 X억/년`. 업종은 편집 탭에서.
- 지게차 머리글: 업체수·대수(계약 대수/견적 대수)·금액 모두 데이터 합계.
- 머리글 없는 붙여넣기: 값 모양으로 열을 찾는다(계약형태 코드 `NN-이름`, 6자리 코드 다음 칸=업체명, `21-견적서`=견적, `01-신규계약`·계약기간=계약, 날짜=기안일→월, `01-연간` 다음 금액 등).
- 부서가 없으면 같은 코드의 다른 행(견적 등)에서 부서를 가져오고, 못 찾으면 점검 목록에 올린다.

## 붙여넣기 점검 요약 (붙여넣으면 바로 보여줌)
- 예상매출액과 효과금액이 다른 행(어느 값을 썼는지 표시)
- 서술 속 예상매출과 금액 열이 다른 행
- 서술을 다른 열에서 찾은 행 / 서술 없음
- 영남 외 지점이라 뺀 행 수, 부서를 못 찾은 행
- 계약형태로 다른 사업에 옮긴 행
- 기준월·기준월+1이 아니라 뺀 행
- 전월 머리글(양식 값)과 데이터 건수·합계 차이

## 당월 손익개선 블록 (PPS 추진계획 표 안, 항목 `손익개선`)
- 데이터: 진행중·완료를 한꺼번에 붙인다. 머리글이 2줄(병합)이라 두 줄을 합쳐 열 이름을 만든다.
- 진행사항: `완료` → 계약확정, `진행중` → 협의중.
- 열 대응: 부서명=팀/권역, 구분=단가인상구분(LPS품의), 업체명=계약처명, 예상매출=년예상효과(천원, 그대로), 세부내용=비고(내용).
- 정렬: 년예상효과 큰 순. 최소 금액 기본 0, 건수 조정 가능.
- 머리글 (N업체 X억): 붙여넣은 데이터로 계산. 세부내용 다듬기 규칙 동일(효과금액 표기도 같은 규칙).

## 서술 (본부 중점 추진사항·권역별 영업추진 계획)
- HTML 입력칸에 직접 쓰고, 엑셀 해당 자리에 줄 단위로 넣는다.

## 타겟업체 (본부 영업타겟업체 영업진행내역 및 계획)
- 상단 표 2개 붙여넣기: `▣ 타겟업체 전체 진행내역`(사업별), `▣ 타겟업체 금주 진행내역`(권역별).
- 목록 붙여넣기(8·9월 함께). 열: 사업구분, 팀/권역, 팀/지점, 담당, 코드, 업체명, 예상매출(年), 신규/점유율확대, 주간적용여부, 시행일(YYYYMMDD), 진행단계, 효과금액(年), 25년 영업진행사항.
  - 월 분류: 시행일의 월. 기준월 → `◎ 타겟업체 N월 영업진행 현황`, 기준월+1 → `◎ 타겟업체 N+1월 영업계획` 표.
  - 항목: PPS/물류기기→PPS, SCM(지게차 제외)→SCM, 산업자재유통, 지게차. 순서 PPS→SCM→산업자재유통→지게차.
  - 진행사항: 진행단계(계약→견적→방문 순). 부서명=팀/권역, 구분=신규/점유율확대 열, 업체명, 예상매출=**효과금액(年)**, 세부내용=25년 영업진행사항.
  - 블록 안 효과금액 큰 순, 기본 전 건.
- 기준월+1 계획의 ▷ 문장: 세부내용이 비슷한 업체를 묶어 초안 자동 작성(업종·영업유형 기준), HTML에서 수정.
  - 형식: `▷ {업종군} 업체 {영업유형} 영업 추진` / `- 업체(지역, 업종 물동량, X억), …`
- 경쟁사(BIGS)는 나중에 작업.

## 농산 및 국고보조업체
- 상단 표 붙여넣기: `◎ 영남본부 전체 현황`(권역별), `▶ 농산업종 2차 타겟 현황`, `※ 2차 타겟업체 …` 주석.
  - `▶ 전체 대상업체 현황` 한 줄(대상·경쟁사매출 억·KPP계약·KPP매출 억·2차 타겟·예상매출 억·계약율)은 권역별 표 본부 행에서 자동 계산.
  - 2차 타겟 방문진행율 = (방문+견적+계약완료) ÷ 대상 업체수 (수식 유지).
- 목록 붙여넣기(8·9월 함께). 열: (실적)팀/권역, 팀/지점, 담당자, 구분, 코드, KPP 거래처명, BIGs 농산 국고보조이탈, 25년 국고보조, 경쟁사매출, PPS 매출, 업체운영여부, 파렛트사용형태, 계약가능여부, 불가사유, 최종방문일(`8월4주`), 진행단계, 예상매출, 세부내용.
  - 월 분류: 최종방문일의 월.
  - 항목 `농산업체`, 진행사항=진행단계(계약완료→계약, 계약→견적→방문 순), 부서명=팀/권역, 구분=구분, 업체명=KPP 거래처명, 예상매출=예상매출, 세부내용.
  - 예상매출 큰 순, 기본 전 건.
- 기준월+1 `■ 중점 추진사항` ▷ 문장: 타겟과 같은 방식으로 묶어서 초안 작성.

## 미정 (다음 단계에서 확인)
- 서술(본부 중점·권역별 계획), 타겟/경쟁사, 농산 붙여넣기 형태
