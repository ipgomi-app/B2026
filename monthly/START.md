# 영남영업본부 월간 영업회의자료 · 시작 안내 (새 채팅용)

## 목표
엑셀에서 **복사 → 붙여넣기**만으로 월간 영업회의자료(xlsx)를 **완성본과 같은 서식**(색, 글자 크기, 테두리, 병합, 열 너비, 수식)으로 만드는 단일 HTML 도구를 만든다.
- 방식은 주간 엔지니어링 도구(`eng/`, 브랜치 `claude/optimistic-cannon-0czsws`)와 같다.
- 브라우저 안에서만 처리하고, 결과는 엑셀 파일로 받는다.

## 입력 (사용자가 새 채팅에 올리는 파일)
1. **완성본**: 지난달 월간회의자료 엑셀. 출력 서식의 기준이다.
2. **로우데이터 양식**: 붙여넣기용 시트. 완성본 안의 표는 이 시트들에서 가져온다.
3. **전월 / 당월 영업현황**

## 완성본에 들어가는 내용
- **전월 계약/견적 현황**: 사업항목별로 정리한다.
- **당월 진행 중 견적/계약 현황**
- **타겟/경쟁사 영업현황**: 타겟/경쟁사 내용을 붙여넣은 그대로 쓴다.
- **농산업종 영업현황**: 표가 따로 있으며, 표마다 그대로 붙인다.

## 1단계: 구조 파악만 (아직 만들지 않는다)
- 완성본의 시트 목록, 시트마다의 표 위치와 머리글, 병합·서식을 정리한다.
- 칸마다 수식인지 입력값인지 구분하고, 수식이 어떤 시트·범위를 참조하는지 정리한다.
- 완성본의 각 표를 로우데이터 양식의 어느 시트·열에서 가져오는지 연결표로 만든다(집계, 필터, 정렬 규칙 포함).
- 전월/당월 현황이 어느 표에 어떻게 들어가는지 정리한다(월 이동: 당월이 다음 달에는 전월이 된다).
- 모호한 점은 질문 목록으로 정리해서 사용자에게 확인받은 뒤 2단계로 간다.

## 2단계 이후 (확인 후 진행)
- `monthly/` 폴더에 `index.html`, `engine.js`, `kit.js`, `tools/make-kit.js`, `README.md`를 만든다.
- `eng/`의 방법을 재사용한다.
  - 완성본에서 데이터를 모두 지운 서식 틀(kit)을 base64로 넣는다.
  - 붙여넣은 TSV(줄바꿈이 든 따옴표 셀 포함)로 값을 채운다.
  - 참고할 함수(`eng/engine.js`): `loadWorkbook`(숨은 정의된 이름 제거), `snapRow`/`writeRow`, `parseTSV`, `templateFromPaste`, `saveWorkbook`, `stripResults`, `fullCalcOnLoad`
- `eng/vendor`의 ExcelJS 4.4.0과 JSZip 3.10을 쓴다.
- 붙여넣기 칸마다 초기화 버튼을 둔다.
- 검증
  - LibreOffice headless로 다시 계산한 값을 완성본과 비교한다(수식·라벨 차이 0 목표).
  - Playwright + Chromium(`/opt/pw-browsers`)으로 화면에서 생성까지 돌려 본다.
- 완성되면 단일 파일 HTML(스크립트 인라인)도 만들어 전달한다.

## 지켜야 할 것
- 저장소는 **공개**다. 업체명, 담당자, 금액, 서술 같은 업무 데이터와 xlsx 파일은 절대 커밋하지 않는다.
  - 커밋은 도구 코드와 데이터를 지운 틀만 한다.
  - `make-kit.js`로 누출 검사를 하고, 걸리면 중단한다.
- 올린 파일과 작업용 복사본은 스크래치패드에만 둔다.
- 답변은 한국어로, 짧게 한다.
