# 주간회의 완전자동화 — 현황과 남은 계획 (재구성본)

기준 시각: 2026-09-28 22:00 (한국시간). 아래 시각은 모두 한국시간이다.

이 문서는 "주간회의 완전자동화 계획"이라는 이름의 원본 문서가 저장소(브랜치 전체)·Google Drive·Gmail·Claude 아티팩트 어디에도 없어서,

## 1. 목표

매주 LPS/AMS 화면과 엑셀에서 **복사 → 붙여넣기**만으로 주간회의 자료(권역별 시트, 본부 시트, 미수채권, 타겟·경쟁사, 농산업종, 단가인상, 엔지니어링, 담당자 활동 대시보드)를 브라우저 안에서 만들고, 원본 서식 그대로 엑셀(xlsx)로 받는다.

- 서버 없음. 붙여넣은 데이터는 브라우저 안에서만 처리한다.
- 저장소는 공개이므로 회사 데이터와 xlsx 파일은 커밋하지 않는다. 도구 코드와 데이터를 지운 서식 틀(kit)만 올린다.
- 월간 회의자료(`monthly/`)도 같은 방식으로 만든다.

## 3. 9/28 추가 작업 (세션 "주간회의 자동작성 HTML", 브랜치 `claude/confident-dijkstra-imhkuo`)

**미수금 취합 탭**
- AMS 수금내역 형식 파서: 거래처 코드별 결제금액 합산, 수금일이 금주 기간이면 금주수금 O, 최종수금일 반영.
- 기준 청구년월 자동 인식(1번 시트 제목·머리글)과 입력칸 수정. 월별 자료는 기준월까지만 써서 청구년월·연체개월·완납 판정.
- 금주 수금 완료 업체의 금주 세부내역 자동 작성: `연체청구월 / 품목, M/D일 결제 완료` 형식(금액 문구는 뺌).
- 3번 수금 데이터가 있으면 월별보다 우선. 월별 자료를 기본 틀로 두고 수금금액·수금일만 덮어쓰기.
- 날짜 형식 추가 인식(YYYY/MM/DD, YYYY.MM.DD, YYYYMMDD, 년월일 표기). 월별 미수금이 모두 0인 업체도 완납 처리.
- 6번 금주 내역: 머리글 위치와 무관하게 행 안에서 코드·금액·내역을 찾아 읽음.
- 1~4번 칸은 붙여넣는 즉시 인식 결과 표시.

**주간회의자료 생성 구역(신설)**
- ① 금주 본부 미수금 합계표, ② 금주 엑셀취합 완료 데이터로 구역을 나누고, 취합 결과는 5번으로 이동.

- 잔여 미수금·그룹 합계·요약표(업체수 COUNT, 합계 SUM, 수금업체 COUNTIF)를 수식으로 연결.
- 코드·연체개월·결제기일을 숫자로 저장, 요약표 숫자 칸 흰 바탕, 텍스트 숫자 경고 끔.
- 구분 병합이 겹쳐 엑셀 복구 오류가 나던 문제 수정.

**서식 복사**

## 5. 남은 과제 (계획)

1. **브랜치 통합과 배포.** 같은 파일의 다른 판이 브랜치마다 따로 있다.
   - `weekly/dash.html`: confident 브랜치는 9/24 판(86KB), weekly-dash·bardeen 브랜치는 9/27 판(147KB).
   - `weekly/영남자동 V1.0.html`: confident 브랜치가 9/28 최신(187KB), bardeen·weekly-dash는 9/27 판(161KB).
   - `weekly/eng.html`(구판) vs `eng/`(신판, xlsx 서식 유지).
   - 할 일: 파일마다 최신 판을 골라 한 브랜치로 모으고 `main`에 병합해 GitHub Pages로 배포한다. 구판(`weekly/eng.html`, `nongsan2.html`)은 정리 여부를 정한다.
2. **V3.0 결정.** bardeen 세션이 작성한 V3.0 프롬프트를 확인해 그대로 만들지, 항목 이름을 바꿀지 정한다. 프롬프트 본문은 그 세션 대화에만 있고 커밋되지 않았다.
3. **미수금 취합 마무리.** 9/28 작업이 진행 중 상태로 끝났다. 실제 금주 데이터로 ①·② 구역과 xlsx 저장을 검증하고, 다른 탭에서 뺀 안내 그림 정책을 확정한다.
4. **미자동화 항목.** 경쟁사(BIGS) 자료(monthly), 단가인상 품목명이 항상 "단가인상"으로 나오는 한계(V2), 엑셀 셀 안 줄바꿈이 있는 업무일지가 행으로 갈라지는 문제.
5. **본부 시트 상단 자동 갱신 확인.** 주간회의 스킬 규칙에 있는 `예상매출` → `▶ 2026년 예상매출`·`▶ 사업항목별 매출` 갱신이 도구로 만들어졌는지 확인한다. 금주요약 탭은 금주 실적 표와 26년 누계(전주 누계 + 금주 계약)까지 만든다.
6. **검증 자동화.** V2.0만 Playwright 검증이 있다. 버전1·2 도구와 미수금 취합은 수동 확인에 의존하므로, 데이터를 지운 샘플로 회귀 테스트를 만든다.
7. **사용법 문서.** 사용설명서 탭을 뺐으므로 탭별 사용 순서를 README로 옮긴다. 현재 `weekly/README.md`(bardeen)는 V2.0만 다룬다.

- 주간: 업무일지, 계약·견적, 미수 데이터를 붙여넣고 버튼 한 번으로 권역 시트·본부 시트·미수·타겟·농산·단가인상·엔지니어링을 xlsx로 받는다. 손으로 쓰는 것은 서술(중점 추진사항 등)뿐이다.
