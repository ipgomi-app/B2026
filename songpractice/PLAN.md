# 노래연습 앱 개발 계획 (SongPractice) — 개인용 / 비배포

> 노래를 검색하면 **반주 + 가사 + 악보(음표)** 가 함께 나오고,
> 그 위에서 따라 부르며 연습하는 **나만의 로컬 웹앱**.
> 배포하지 않고 내 PC/폰에서만 쓴다 → 저작권 우회 설계 불필요, 편의성 최우선.

---

## 0. 전제 (배포 안 함 → 달라지는 것)

| 항목 | 배포용이었다면 | 개인용이므로 |
|---|---|---|
| 가사 | 사용자 입력만 | 가사 사이트에서 자동 가져오기 OK (lrclib.org 무료 API, 동기화 LRC 제공) |
| 반주 | YouTube 임베드만 | **yt-dlp 로 MR/원곡 오디오 다운로드**해 로컬 파일로 재생 → 키 변경·속도·구간반복 전부 자유 |
| 악보 | 업로드만 | 원곡에서 **멜로디 자동 추출 → 음표 자동 생성** (basic-pitch / CREPE) |
| 보컬 제거 | 어려움 | **Demucs** 로컬 실행 → 원곡만 있으면 MR 자동 생성 |
| 인프라 | 정적 사이트 | **로컬 Python 서버(FastAPI) + 브라우저 UI**. 무거운 처리는 파이썬이, 화면은 브라우저가 |

→ 결론: **"검색 한 번이면 반주·가사·악보가 자동으로 준비되는" 진짜 자동화**가 가능해진다.

## 1. 사용 흐름 (목표 경험)

```
1. 검색창에 "가수 - 제목" 입력
2. 앱이 자동으로:
   ① YouTube에서 원곡(또는 MR) 검색 → 오디오 다운로드
   ② 원곡이면 Demucs로 보컬/반주 분리 → 반주(MR) + 보컬 가이드 트랙
   ③ lrclib에서 동기화 가사(LRC) 조회 → 없으면 일반 가사 + 자동 정렬(Whisper)
   ④ 보컬 트랙에서 멜로디 추출 → 음표(피아노롤/오선보) 생성
3. 연습 화면: 반주 재생 + 가사 하이라이트 + 음표 커서 + 내 음정 표시
4. 마이크로 부르며 점수 확인, 틀린 구간 반복
```

준비 시간: 곡당 1~3분 (Demucs가 대부분). 한 번 처리하면 캐시.

## 2. 핵심 기능

### 연습 화면
1. **반주 재생** — 로컬 오디오. 속도 0.5~1.5x, 키 ±6반음, A-B 구간반복, 카운트인
2. **가이드 보컬 볼륨** — 분리한 원곡 보컬을 0~100% 섞어 듣기 (처음엔 따라 부르고, 익숙해지면 끄기)
3. **가사** — 현재 줄 강조, 자동 스크롤, 클릭하면 그 줄로 이동
4. **음표** — 피아노롤(기본) / 오선보(VexFlow) 토글. 재생 커서 이동
5. **내 음정** — 마이크 피치를 음표 위에 실시간 오버레이. 구간별 정확도 %, 틀린 부분 표시
6. **녹음** — 내 노래 녹음 → 반주와 섞어 재생, 이전 녹음과 비교

### 곡 준비 (자동 파이프라인)
- 검색 → 다운로드 → 분리 → 가사 → 멜로디 추출 → 저장 (진행률 표시)
- 수동 보정: 가사 오프셋 밀기, 멜로디 옥타브 수정, 내 파일(MR/MusicXML/MIDI) 직접 넣기

### 곡함
- 처리된 곡 목록, 연습 횟수/최고 점수, 즐겨찾기

## 4. 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 백엔드 | **Python FastAPI** (localhost:8000) | 처리 파이프라인 + 파일 서빙 |
| 다운로드 | yt-dlp | 원곡/MR 오디오 (m4a/wav) |
| 보컬 분리 | **Demucs** (htdemucs) | CPU 가능, GPU 있으면 빠름 |
| 가사 | lrclib.org API (동기화 가사) → 없으면 **faster-whisper** 로 오디오에서 가사+타임스탬프 생성 | Whisper는 보컬 트랙에 적용하면 정확 |
| 멜로디 추출 | **basic-pitch**(Spotify) → MIDI | 보컬 트랙 입력, 옥타브·짧은 음 정리 후처리 |
| 프론트 | HTML/JS (Vanilla 또는 Preact), 브라우저 UI | 기존 저장소 스타일과 동일 |
| 오디오 재생 | Web Audio API + SoundTouch.js(WASM) | 키/속도 독립 조절, 반주+가이드 2트랙 믹스 |
| 악보 | 피아노롤 Canvas(기본) + VexFlow(오선보) | |
| 피치 검출 | pitchy (McLeod) | 마이크 실시간 |
| 저장 | 파일시스템 `data/songs/<id>/` + SQLite | 서버가 관리, 브라우저는 fetch |

### 곡 폴더 구조
```
data/songs/<id>/
  meta.json        # 제목, 가수, 키, BPM, 오프셋, 연습기록
  original.m4a     # 원곡
  accompaniment.wav# Demucs 반주
  vocals.wav       # Demucs 보컬 (가이드 + 멜로디 추출 소스)
  lyrics.lrc       # 동기화 가사
  melody.mid       # 추출 멜로디
```

## 5. 개발 단계

### M1. 파이프라인 먼저 (CLI) — 3~4일
- [ ] `prepare.py "가수 - 제목"` 한 줄로 다운로드→분리→가사→멜로디까지 자동
- [ ] 결과물 폴더 생성, 각 단계 실패 시 건너뛰고 나머지 진행
- [ ] 샘플 3곡으로 품질 확인 (멜로디 추출 후처리 튜닝)

### M2. 연습 화면 — 1주
- [ ] FastAPI로 곡 목록/파일 서빙
- [ ] 2트랙(반주+가이드) 재생, 속도/키/A-B
- [ ] LRC 가사 하이라이트, 피아노롤 + 커서
- [ ] 오프셋 조절 UI

### M3. 마이크 피드백 + 녹음 — 1주
- [ ] 실시간 피치 오버레이, 구간 정확도
- [ ] 녹음 저장, 반주와 믹스 재생, 기록 그래프

### M4. 다듬기 — 수시
- [ ] 브라우저에서 검색→준비 버튼(진행률 표시)
- [ ] 오선보 뷰(VexFlow), 단축키, 폰에서 접속(같은 Wi-Fi, http://PC-IP:8000)
- [ ] 곡함 정리, 즐겨찾기

## 7. 리스크

| 리스크 | 대응 |
|---|---|
| Demucs CPU 처리 느림 (곡당 2~5분) | 백그라운드 처리 + 진행률, GPU 있으면 자동 사용 |
| 멜로디 자동 추출이 지저분함 | 보컬 트랙만 입력, 최소 음길이/신뢰도 필터, 옥타브 정리, 수동 편집 허용 |
| 마이크에 반주가 섞임 | 이어폰 사용, 에코캔슬 옵션 |
| 파이썬 환경 설치 부담 | `setup.sh` 한 번에 venv+의존성, 실행은 `run.sh` |

## 8. 결정 필요 사항

1. **PC 사양**: GPU(NVIDIA) 유무 → Demucs/Whisper 속도가 크게 달라짐
2. **주 사용 기기**: PC 브라우저만? 폰에서도(같은 Wi-Fi 접속)?
3. **악보 형태**: 피아노롤이면 충분한지, 오선보까지 필요한지
4. 확정되면 **M1(파이프라인 CLI)** 부터 착수
