미수금 금액 단위 원

1. 금주 데이터 붙여넣기 (엑셀에서 필터된 행 복사 → 붙여넣기)

2. 전주 누계 (지난주 회의자료의 "2차 타겟 현황" 표를 복사해서 붙여넣기 → 적용)

붙여넣은 전주 표가 그대로 표시됩니다(아래 결과와 비교용). 이번주 누계 = 전주 누계실적 + 금주 실적. 방문진행률 = (누계 방문+견적+계약완료) ÷ 대상 업체수.

3. 결과

주요업체 선정 기준 계약 → 견적 → 방문 순, 효과금액 상위순 · 바꾸면 바로 반영
주요업체 데이터 행만 B~Q 열 위치 그대로(업체명 2칸, 진행사항 9칸) 값으로 복사합니다. 회의자료 주요업체 표 첫 행의 "팀/지점" 셀을 선택하고 Ctrl+V. 셀은 클릭해서 수정할 수 있습니다.

1. 금주현황 붙여넣기 권역 소계 3행 + 본부계 (업체수·보증보험 미가입·1~6개월·소계·미수채권 총계·지난주·지난주 수금액)

2. 미수금 데이터 붙여넣기 데이터 탭의 미수금 칸과 같은 자료 (금액 단위 원)

3. 미수금 현황 영남 소속 · 100만원 이상

세부 진행내역·수금금액 칸은 클릭해서 직접 입력할 수 있고, 수금금액을 넣으면 잔여 미수금과 위 요약표가 다시 계산됩니다. 서식 복사: 엑셀 상세표의 기존 데이터 행을 지운 뒤 첫 데이터 행의 구분 셀(B열)을 선택하고 일반 붙여넣기(Ctrl+V)하면 구분 병합·배경색·테두리·숫자 형식이 함께 들어갑니다.

1. AMS 채권관리현황 › 업체별(합계)

2. AMS 채권관리현황 › 업체별(상세)

3. 전주 미수금 시트 (구분·법조치현황 이어받기, 선택)

4. 취합 결과 영남 소속 · 기준금액 이상 · 법조치/회생채권/결제지연

미수채권 = 업체별(합계) 금액, 연체개월 = 청구 개월 수(최초 청구월이 최근 청구월보다 6개월 이상 오래되면 6), 결제기일 = 조건, 보증금액 = 보증금 + 보증보험(상세 우선). 구분·법조치현황은 3번 전주 시트의 같은 코드에서 이어받고, 없으면 결제지연·공란. 결과는 미수금 탭에도 같이 표시되며 세부 진행내역·수금금액은 표에서 직접 입력할 수 있습니다.
