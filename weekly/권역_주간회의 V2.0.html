분류·집계 기준 보기 (V2.0)
① 사업별 계약·견적은 붙여넣은 계약·견적 자료(결재완료)만 집계합니다. V1과 같습니다.
②③·상세는 업무일지를 활동 1건 = 주 분류 1개로 다시 분류합니다. 활동 1건은 업무일지 상세 1행입니다. 견적 연동 자동일지("일자 : … 업체코드 : … 제목 : [..] 견적서"), 휴가, 내용이 짧은 직출·직퇴 메모(직출·직퇴 표식을 뗀 내용이 20자 미만; 내용이 있으면 그 내용으로 분류), 상세 없는 DRS일괄작성, 첨부파일 행, 담당자 이민승은 제외합니다(휴가·직출은 '제외' 칸에 셉니다).
주 분류 10개 — 영업: 신규·전환영업 / 기존확대·손익 · 운영: 신규업체확인 / 입고미회수 / 회수 / 재고실사 / 수불·전산 / 클레임 · 관리: 채권·리스크 / 기타업무. 판정 순서는 ⑴ 엔지니어링 방문양식 → 신규·전환영업, ⑵ 담당자가 쓴 활동명("1. 활동명 2. …", "* 활동명", 시간기록 뒤 문구)의 키워드, ⑶ 상세구분 코드 기본값(입고미회수·미입고확인 → 입고미회수, 공파렛트확인 → 회수, 수불관리·실착지오류·사장업체 → 수불·전산, 신규업체 → 신규업체확인, 재고실사 → 재고실사, 미수금/보증·법적대응 → 채권·리스크, 산업자재유통·SCM·물류장비·RRPP·엔지니어링·경쟁사·신규계약 → 신규·전환영업, 재계약협의·단가협의 → 기존확대·손익), ⑷ 본문의 강한 신호(미수금·지급명령 / 견적 제출·제안·영업·계약 협의 / 단가인상·재계약)로 기본값 변경, ⑸ 나머지 본문 키워드, ⑹ 판정 불가 → 확인필요. "영업지원 입고미회수"의 영업지원은 영업이 아닙니다.
태그: 사업(PPS/산업자재/SCM/지게차/RRPP/엔지니어링), 대상(신규업체/계약처/실수요처/경쟁사/건설현장), 결과(회수완료·회수예정·회수불가·견적·계약·자료수정·입금·약정), 복합(영업·운영·관리 신호가 2개 이상), 비대면(유선·카톡·문자·메일). 태그는 건수에 중복으로 세지 않습니다. 경쟁사·엔지니어링·산업자재는 활동분류가 아니라 태그입니다.
중복 제거: 같은 일지번호의 같은 문장, 같은 날·같은 담당자·같은 업체·같은 주 분류는 1건입니다.
③ 성과 연결: 3번 칸의 계약·견적 자료(결재완료, 반려 제외)를 담당자 + 업체코드(또는 업체명 앞 4자)로 연결합니다. 영업→견적·계약 = 영업활동 업체 중 어느 활동이든 30일 안(계약은 7일 전부터)에 견적·계약이 있는 업체, 견적→계약 = 견적 업체 중 이후 신규계약이 있는 업체, 계약 근거일지 = 신규계약 중 계약 전 30일 안에 같은 업체 일지가 있는 건. 단가인상은 같은 담당자·같은 날·같은 내용의 일괄 품의를 묶어 "(n건 일괄)"로 표시합니다. 연결은 붙여넣은 자료 전체에서 찾고, 표에는 선택한 기간의 활동·계약·견적만 셉니다. 금액은 천원입니다.
기록 품질: 반복문구 = 같은 담당자가 같은 문장을 3회 이상 쓴 활동 비율, 수량기재 = 매·대·박스·롤 수량이 있는 비율, 결과기재 = 결과 태그가 있는 비율.
신호(사실만 표시, 판단은 권역장): 쏠림(한 분류 60% 이상, 지시 활동 주 제외, 8건 이상), 영업 연결률 30% 미만(영업 업체 10곳 이상, 30일 기준), 견적→계약 10% 이하(견적 업체 10곳 이상), 기록 누락(신규계약은 있는데 30일 안 일지 없음), 반복 업체(같은 업체·같은 분류 3주 이상, 결과 없음), 형식문구 반복 50% 이상(20건 이상), 견적 중복(같은 업체·사업 2회 이상). 쏠림·연결률·반복은 4주 누적·월간·전체에서만 계산하고 주간은 추이만 봅니다. 건수는 업무량이 아닙니다(짧은 확인 방문 1건과 협상 1건은 같은 1건).
지시 활동 주: 한 주에 담당자 40% 이상(4명 이상)이 같은 분류에 60% 넘게 몰리면 '지시 활동 주(추정)'로 표시하고 개인 쏠림에서 뺍니다. 주차별 표의 '지시' 체크로 직접 켜고 끌 수 있습니다(이 브라우저에 기억).
키워드: 검색칸에 넣으면 표②(키워드 건수·업체 열 추가, 분류 건수도 키워드에 맞는 활동만), 관련 업체 목록, 상세가 그 키워드로 좁혀집니다. 업체명·코드·활동명·태그·분류명·내용에서 찾고, 띄어쓰기는 모두 포함(AND), 쉼표는 하나라도(OR)입니다. 표①③과 카드는 바뀌지 않습니다.
기간: 주간은 선택한 주(금~목), 4주 누적은 선택한 주를 포함한 직전 4주, 월간은 선택한 주의 금요일이 속한 달, 전체는 붙여넣은 전부. '기간 무시'를 켜면 주간 대신 전체를 봅니다. 표①은 V1과 같이 선택한 주(또는 기간 무시)를 따릅니다.
주간회의 자료(2번)·목표 진척도(3번)는 V1 방식 그대로 계산합니다. 목표 표 머리글에 새 분류명(신규·전환영업, 기존확대, 신규업체확인, 회수, 수불·전산, 채권, 기타업무)이나 영업활동/운영활동/관리활동을 쓰면 새 분류로 셉니다. V1 대비 수정: 견적 자료에 10억 이상 건이 있을 때 견적 금액 전체가 1/1000로 줄던 오류와 H로 시작하는 건설현장 코드를 못 읽던 오류를 고쳤습니다.
표·상세 크기 100%
