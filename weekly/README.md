## V2.0 사용법

1. 업무일지, 계약 데이터, 견적 데이터를 붙여넣고 **대시보드 생성**을 누른다.
2. `기간(②③·상세)`로 주간(선택 주) / 4주 누적 / 월간 / 전체를 고른다. `기간 무시`를 켜면 전체를 본다. 표①은 V1과 같이 선택한 주(또는 기간 무시)를 따른다.
3. 카드(영업·운영·관리·기타)나 `분류 필터`의 "활동분류 (V2)"를 누르면 표②와 상세가 그 분류로 좁혀진다. 표① 항목이나 계약구분을 고르면 계약·견적 상세만 보인다.
4. 주차별 표의 **지시** 체크로 "지시 활동 주"를 켜고 끌 수 있다(브라우저에 기억, `localStorage.v2_camp`).
5. 주간회의 자료(2번)의 엑셀 파일명은 `권역_주간회의_(주차).xlsx`로 V1과 같다.
6. 목표 진척도(3번) 머리글에 새 분류명(신규·전환영업, 기존확대, 신규업체확인, 회수, 수불·전산, 채권, 기타업무)이나 영업활동/운영활동/관리활동을 쓰면 V2 활동으로 센다. 옛 이름(신규업체, 입고미회수, 수불관리 …)은 V1 방식으로 센다.

## V2 분류 기준

### 단위와 제외
- **활동 1건 = 업무일지 상세 1행 = 주 분류 1개.** 사업·대상·결과는 태그로 붙이고 건수에 중복으로 세지 않는다.
- 제외: 견적 연동 자동일지(`일자 : … 업체코드 : … 제목 : [..] 견적서` 양식, 견적 리스트 성과로만 센다), 휴가·연차·반차, 내용이 짧은 직출·직퇴 메모(표식을 뗀 내용이 20자 미만; 내용이 있으면 그 내용으로 분류)(제외 칸에 표시), 상세 없는 DRS일괄작성, 첨부파일 행, 권역장(이민승).
- 중복 제거: 같은 일지번호의 같은 문장은 1건. 같은 날·같은 담당자·같은 업체·같은 주 분류의 상세 여러 행은 1건으로 세되 내용·결과 태그는 합쳐 보존(상세에 ‖로 표시). 엑셀 셀 안 줄바꿈은 앞 줄에 이어 붙이고, 부모 일지가 없는 상세 행은 제외.

### 판정 순서
1. 본문이 엔지니어링 방문양식(`프로젝트 구분 : 엔지니어링`)이면 신규·전환영업.
2. 담당자가 쓴 **활동명**(`1. 활동명 2. …`, `* 활동명`, `[머리] 활동명`, 시간기록 뒤 문구)에 위 표의 키워드가 있으면 그 분류. 우선순위는 제외 → 채권 → 클레임 → 기존확대 → 신규영업 → 수불·전산 → 신규업체확인 → 재고실사 → 회수 → 기타업무.
3. 활동명이 없으면 상세구분 코드 기본값.
4. 본문의 강한 신호가 있으면 기본값을 바꾼다. 운영 기본값을 영업으로 바꾸려면 `견적 제출·전달·요청 / 제안 / 영업 / 계약 협의·체결 / 경쟁사 전환·사용`이 있어야 하고, 채권으로 바꾸려면 `미수금 / 입금 요청·독촉 / 채권 / 법적 / 지급명령 / 가처분`, 기존확대로 바꾸려면 `단가인상·협의 / 재계약 / 증차`가 있어야 한다.
5. 그래도 없으면 나머지 본문 키워드, 마지막은 **확인필요**.

6~9월 부산권역 4,118건 기준 판정 근거: 활동명 69%, 상세구분 기본값 21%, 본문 신호 3%, 엔지니어링 양식 2%, 확인필요 3건.

### 태그
- 사업: 엔지니어링 / 지게차 / 산업자재 / RRPP / SCM / PPS(기본)
- 대상: 경쟁사 / 건설현장 / 신규업체 / 실수요처 / 계약처
- 결과: 회수완료 · 회수예정 · 회수불가 · 견적 · 계약 · 자료수정 · 입금 · 약정
- 복합: 영업·운영·관리 신호가 2개 이상인 활동 · 비대면: 유선·카톡·문자·메일·통화

### 성과 연결 (표③)
- 2번 칸의 계약·견적 자료(결재완료만; 결재중·대기·임시저장·반려·상태 없음은 제외)를 **같은 담당자** + 업체코드(또는 괄호·주식회사 등을 뺀 업체명이 완전히 같은 업체)로 연결한다. 연결은 붙여넣은 자료 전체에서 찾고, 표에는 선택한 기간의 활동·계약·견적만 센다.
- 영업→견적·계약: 영업활동 업체 중 어느 활동이든 30일 안(계약은 7일 전부터)에 견적·계약이 있는 업체 비율.
- 견적→계약: 견적 업체 중 첫 견적 이후 신규계약이 있는 업체 비율.
- 계약 근거일지: 신규계약 중 계약일 전 30일 안에 같은 업체 일지가 있는 건. 없으면 "기록 누락" 신호.
- 단가인상: 같은 담당자·같은 날·같은 내용(앞 20자)의 일괄 품의는 `(n건 일괄)`로 표시. 금액은 천원.

### 기록 품질
반복문구 = 같은 담당자가 같은 문장을 3회 이상 쓴 활동 비율 · 수량기재 = 매·대·박스·롤 수량이 있는 비율 · 결과기재 = 결과 태그가 있는 비율.

### 지시 활동 주
한 주에 담당자 40% 이상(4명 이상)이 같은 분류에 60% 넘게 몰리면 "지시 활동 주(추정)"로 표시하고 개인 쏠림에서 뺀다. 2026년 8/7주·8/14주(신규업체 확인)가 여기에 해당한다. 주차별 표에서 직접 켜고 끌 수 있다.

### 3번 칸: 차량운영 → 차량관리 (2026-10-04)
항목별 계약·견적 9칸을 없애고 차량운영 1칸으로 바꿨다. 계약·견적은 2번 LPS 칸에서만 받는다(2026-10-05: LPS 계약·견적 = 2번, 차량운영 = 3번으로 순서 변경).
- 입력: 차량운영 월 조회 결과(차량별: SEQ … CAR_NUM, CAR_WGT_TYP, CAR_OWN_NAM, EMP_NAM, GU, CST_QTY00=전월 합계, CST_QTY01~31=일자별, CST_QTY, N_AVG, B_AVG=전월 일평균). 담당자별 자료(차량 열 없음)도 읽는다. SEQ=1 행만 쓰고 소계·권역계는 다시 계산한다. **예측량은 쓰지 않는다.**
- 두 달에 걸친 회의 기간은 전월분 뒤에 당월분을 이어 붙인다(마지막 자료 = 회의 종료일이 속한 달, 전월 합계로 순서 확인).
- 화면: 대시보드 기본 화면에는 띄우지 않고, 카드의 **차량관리**를 누르면 차량 표와 일자 상세만 보인다(다시 누르면 원래 화면).
- 차량 표: 지점 / 담당자 / 차량번호·톤수·기사명. 금주(회의 기간) 운행일·회전수·업체수·회수량 옆에 전주(회의 시작 전 7일) 대비 ▲▼, 20% 이상 감소·운행일 2일 이상 감소는 분홍. 회전당 회수, 일평균 회수(전월 일평균 대비), 미운행, 전일대비 급변, 당월 누계. 담당자 소계·지점 계·권역 계.
- 일평균 전월 → 당월: 자료의 B_AVG(전월평균)·N_AVG(당월평균)를 회수량·업체수·회전수별로 나란히 보여주고 증감 %를 붙인다(20% 이상 감소는 분홍).
- 미운행 = 일요일과 권역 전체 휴무일(그날 어느 차량도 회수·회전이 없는 날)을 뺀 날 중 회수·회전이 없는 날. 결차 = 금주 내내 회수·회전이 없는 차량.
- 전일대비 급변 = 회수량이 직전 운행일(일요일 제외) 대비 ±50% 이상이고 30매 이상 차이 나는 날.
- 일자 상세: 전주~금주 날짜 × 회수량·업체수·회전수, 일요일·휴무일 회색, 미운행 분홍, 급변 ▲▼.

### 주간회의 자료 · 금주 운영관리 현황 (2026-10-04)
KPP 운영 소관 내용만 올린다.
- 계약 자료: **재출고개선(08-재출고개선)·재출고 계약·타용도 계약만**. 신규·경쟁사 전환·점유율 확대·단가인상 계약과 견적은 모두 뺀다. 계약은 매수와 관계없이 올린다.
- 업무일지: 재입고(재고증가 재입고 협의·추가 재입고·재입고 청구), 법조치(법무팀·법무파트·공문·내용증명·가압류·가처분·지급명령·변상), 차량(결차·용차·증차·감차·차량 운영·투입·고장·배차 문제 등).
- 견적·신규·경쟁사·전환·점유율·예상매출 같은 영업 내용과 섞인 재입고·계약 언급은 뺀다. 차량은 고객사 증차·지게차 판매(영업·니즈·납기·견인차)도 뺀다. "쌍용차"처럼 낱말 속 '용차'는 잡지 않는다.

### 회의 기간 (주차 선택)
날짜를 고르면 그 주 금요일~목요일이 기간이 되고 종료일 칸이 목요일로 채워진다. 회의 기간이 다르면 종료일만 바꾼다(예: 9/25~10/2, 최대 14일). 이 기간은 표①·주간 보기·주간회의 자료·주차별 추이에 모두 쓰이며, 주차별 추이에서는 한 칸("9/25~10/2")으로 묶는다. 그 앞 주는 금~목, 바로 뒤 주는 종료일 다음 날부터 센다.

## V1 대비 수정
- 견적 자료에 10억 원 이상 건이 하나라도 있으면 견적 금액 전체가 1/1000로 줄던 오류(표①)를 고쳤다. 같은 자료로 V1과 V2의 표① 금액이 다르면 V2가 맞다.
- `H41205`처럼 영문으로 시작하는 건설현장 코드를 지점코드로 잘못 읽던 오류를 고쳤다.
- 알려진 한계: 단가인상 품목명이 항상 "단가인상"으로 나온다(V1과 같음). 엑셀 셀 안에 줄바꿈이 있는 업무일지는 행이 갈라질 수 있다.

## 검증
`권역_주간회의 V2.0.html`의 분류 엔진은 파이썬 프로토타입과 같은 규칙으로 만들었고, 2026년 6~9월 부산권역 업무일지 4,118건·계약 178건·견적 478건으로 담당자별 9분류 건수·월간 집계·지시 활동 주·성과 연결 지표가 일치하는지 Playwright로 확인했다. 표①은 위 금액 오류 수정분을 빼면 V1과 같다. 회사 자료는 저장소에 넣지 않는다.

## 2026-10-02 코드점검 반영
외부 점검 보고서 18건 중 15건을 고쳤다.
- 보안: `esc()`가 따옴표도 바꾸도록 수정(속성 주입 차단). 색인 객체를 `Object.create(null)`로 바꿔 `__proto__` 같은 코드로 중단되지 않게 함.
- 집계: 계약·견적은 **결재완료만**(결재중·대기·임시저장·반려·상태 없음 제외, 제외 건수 표시). 중복 키에 구분(정규화)·사업(원본 계약형태)·금액·내용 전체 포함. 성과 연결은 **같은 담당자 + 코드 또는 업체명 완전 일치**. 헤더형 자료에서 업체코드 열을 업체명보다 먼저 인식. 계약 조회의 예상매출이 0이어도 효과금액을 매출로 읽지 않음. 2/31 같은 잘못된 날짜 거부, 날짜 없는 행은 '기간 무시'에서만 포함.
- 입력: 엑셀 셀 안 줄바꿈이 있는 업무일지를 앞 줄에 이어 붙임. 부모 일지가 없는 상세 행은 다른 일지에 붙이지 않고 제외(건수 표시).
- 갱신: 업무일지를 고치면 대시보드 재생성 전까지 '다시 생성' 안내가 뜨고 목표 진척도는 새 자료로 다시 계산. 주차를 바꾸면 이전 주차 작성시트를 비움. 회수예측 입력값은 주차별로 따로 저장.
- 분류: 본문 중간의 "연차·휴가" 언급(상대방 부재)은 제외하지 않음. "계약 체결 불가", "입금 확인 안됨", "회수 완료 여부" 같은 부정·미완 문구는 결과 태그로 잡지 않음. 같은 날 같은 분류 상세는 합치되 내용·결과 보존.
- 기타: 회수예측 %는 % 기호가 있으면 항상 100으로 나눔. 엑셀 생성 실패 시 안내와 버튼 잠금. 2번·3번 입력 영역 HTML 닫힘 오류 수정. 표③·신호 대상자에 일지 없이 계약·견적만 있는 담당자도 포함.
- 반영하지 않은 것: 신호·주차별 표를 4주·월간에서도 표시(사용자 결정으로 전체 기간에서만), TSV 복사 시 수식 시작 문자 처리(붙여넣기 값이 달라져 보류), 회수예측 7열 붙여넣기 정렬, V1 목표 진척도와 V2 지표 명칭 통일, 저장·백업 기능, ExcelJS 로컬 포함.
