# weekly — 영남본부 주간 대시보드

| 파일 | 내용 |
|---|---|
| `dash.html` | V1. 주간 활동 대시보드(표①②③) · 주간회의 자료 · 목표 진척도. 그대로 유지 |
| `권역_주간회의 V2.0.html` | V2. 표①은 V1과 같고, 표②③·상세를 **담당자 활동분류 엔진**으로 교체. 주간회의 자료·목표 진척도는 V1 방식 그대로 |

두 대시보드 모두 입력은 같다. 업무일지(LPS 조회 → 엑셀 복사, 탭 구분), 3번 칸의 계약 데이터·견적 데이터(결재 조회 그대로, 반려 행은 자동 제외).
주차는 금요일~목요일이고 달력에서 고른다.

## V2.0 사용법

1. 업무일지, 계약 데이터, 견적 데이터를 붙여넣고 **대시보드 생성**을 누른다.
2. `기간(②③·상세)`로 주간(선택 주) / 4주 누적 / 월간 / 전체를 고른다. `기간 무시`를 켜면 전체를 본다. 표①은 V1과 같이 선택한 주(또는 기간 무시)를 따른다.
3. 카드(영업·운영·관리·기타)나 `분류 필터`의 "활동분류 (V2)"를 누르면 표②와 상세가 그 분류로 좁혀진다. 표① 항목이나 계약구분을 고르면 계약·견적 상세만 보인다.
4. 주차별 표의 **지시** 체크로 "지시 활동 주"를 켜고 끌 수 있다(브라우저에 기억, `localStorage.v2_camp`).
5. 주간회의 자료(2번)의 엑셀 파일명은 `권역_주간회의_(주차).xlsx`로 V1과 같다.
6. 목표 진척도(3번) 머리글에 새 분류명(신규·전환영업, 기존확대, 신규업체확인, 회수, 수불·전산, 채권, 기타업무)이나 영업활동/운영활동/관리활동을 쓰면 V2 활동으로 센다. 옛 이름(신규업체, 입고미회수, 수불관리 …)은 V1 방식으로 센다.

## V2 분류 기준

### 단위와 제외
- **활동 1건 = 업무일지 상세 1행 = 주 분류 1개.** 사업·대상·결과는 태그로 붙이고 건수에 중복으로 세지 않는다.
- 제외: 견적 연동 자동일지(`일자 : … 업체코드 : … 제목 : [..] 견적서` 양식, 견적 리스트 성과로만 센다), 휴가·연차·반차, 내용이 짧은 직출·직퇴 메모(표식을 뗀 내용이 20자 미만; 내용이 있으면 그 내용으로 분류)(제외 칸에 표시), 상세 없는 DRS일괄작성, 첨부파일 행, 권역장(이민승).
- 중복 제거: 같은 일지번호의 같은 문장, 같은 날·같은 담당자·같은 업체·같은 주 분류는 1건.

### 판정 순서
1. 본문이 엔지니어링 방문양식(`프로젝트 구분 : 엔지니어링`)이면 신규·전환영업.
2. 담당자가 쓴 **활동명**(`1. 활동명 2. …`, `* 활동명`, `[머리] 활동명`, 시간기록 뒤 문구)에 위 표의 키워드가 있으면 그 분류. 우선순위는 제외 → 채권 → 클레임 → 기존확대 → 신규영업 → 수불·전산 → 신규업체확인 → 재고실사 → 회수 → 기타업무.
3. 활동명이 없으면 상세구분 코드 기본값.
4. 본문의 강한 신호가 있으면 기본값을 바꾼다. 운영 기본값을 영업으로 바꾸려면 `견적 제출·전달·요청 / 제안 / 영업 / 계약 협의·체결 / 경쟁사 전환·사용`이 있어야 하고, 채권으로 바꾸려면 `미수금 / 입금 요청·독촉 / 채권 / 법적 / 지급명령 / 가처분`, 기존확대로 바꾸려면 `단가인상·협의 / 재계약 / 증차`가 있어야 한다.
5. 그래도 없으면 나머지 본문 키워드, 마지막은 **확인필요**.

6~9월 부산권역 4,118건 기준 판정 근거: 활동명 69%, 상세구분 기본값 21%, 본문 신호 3%, 엔지니어링 양식 2%, 확인필요 3건.

### 태그
- 사업: 엔지니어링 / 지게차 / 산업자재 / RRPP / SCM / PPS(기본)
- 대상: 경쟁사 / 건설현장 / 신규업체 / 실수요처 / 계약처
- 결과: 회수완료 · 회수예정 · 회수불가 · 견적 · 계약 · 자료수정 · 입금 · 약정
- 복합: 영업·운영·관리 신호가 2개 이상인 활동 · 비대면: 유선·카톡·문자·메일·통화

### 성과 연결 (표③)
- 3번 칸의 계약·견적 자료(결재완료)를 담당자 + 업체코드(또는 업체명 앞 4자; 괄호·주식회사 등 제거)로 연결한다. 연결은 붙여넣은 자료 전체에서 찾고, 표에는 선택한 기간의 활동·계약·견적만 센다.
- 영업→견적·계약: 영업활동 업체 중 어느 활동이든 30일 안(계약은 7일 전부터)에 견적·계약이 있는 업체 비율.
- 견적→계약: 견적 업체 중 첫 견적 이후 신규계약이 있는 업체 비율.
- 계약 근거일지: 신규계약 중 계약일 전 60일 안에 같은 업체 일지가 있는 건. 없으면 "기록 누락" 신호.
- 단가인상: 같은 담당자·같은 날·같은 내용(앞 20자)의 일괄 품의는 `(n건 일괄)`로 표시. 금액은 천원.

### 기록 품질
반복문구 = 같은 담당자가 같은 문장을 3회 이상 쓴 활동 비율 · 수량기재 = 매·대·박스·롤 수량이 있는 비율 · 결과기재 = 결과 태그가 있는 비율.

### 신호 (사실만 표시, 판단은 권역장)
| 신호 | 기준 | 계산 기간 |
|---|---|---|
| 쏠림 | 한 분류가 60% 이상(8건 이상, 지시 활동 주 제외) | 4주 누적·월간·전체 |
| 영업 연결률 낮음 | 영업 업체 10곳 이상, 30일 내 견적·계약 30% 미만 | 4주 누적·월간·전체 |
| 견적→계약 낮음 | 견적 업체 10곳 이상, 계약 10% 이하 | 4주 누적·월간·전체 |
| 형식문구 반복 | 20건 이상, 반복문구 50% 이상 | 4주 누적·월간·전체 |
| 반복 업체 | 같은 업체·같은 분류 3주 이상, 결과 태그 없음 | 4주 누적·월간·전체 |
| 견적 중복 | 같은 업체·사업에 2회 이상 | 4주 누적·월간·전체 |
| 기록 누락 | 신규계약은 있는데 60일 안 일지 없음 | 모든 기간 |

건수는 업무량이 아니다. 짧은 확인 방문 1건과 협상 1건은 같은 1건이므로, 신호는 성과 연결·기록 품질과 함께 본다.

### 지시 활동 주
한 주에 담당자 40% 이상(4명 이상)이 같은 분류에 60% 넘게 몰리면 "지시 활동 주(추정)"로 표시하고 개인 쏠림에서 뺀다. 2026년 8/7주·8/14주(신규업체 확인)가 여기에 해당한다. 주차별 표에서 직접 켜고 끌 수 있다.

## V1 대비 수정
- 견적 자료에 10억 원 이상 건이 하나라도 있으면 견적 금액 전체가 1/1000로 줄던 오류(표①)를 고쳤다. 같은 자료로 V1과 V2의 표① 금액이 다르면 V2가 맞다.
- `H41205`처럼 영문으로 시작하는 건설현장 코드를 지점코드로 잘못 읽던 오류를 고쳤다.
- 알려진 한계: 단가인상 품목명이 항상 "단가인상"으로 나온다(V1과 같음). 엑셀 셀 안에 줄바꿈이 있는 업무일지는 행이 갈라질 수 있다.

## 검증
`권역_주간회의 V2.0.html`의 분류 엔진은 파이썬 프로토타입과 같은 규칙으로 만들었고, 2026년 6~9월 부산권역 업무일지 4,118건·계약 178건·견적 478건으로 담당자별 9분류 건수·월간 집계·지시 활동 주·성과 연결 지표가 일치하는지 Playwright로 확인했다. 표①은 위 금액 오류 수정분을 빼면 V1과 같다. 회사 자료는 저장소에 넣지 않는다.
